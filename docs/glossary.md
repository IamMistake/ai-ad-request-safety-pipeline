# Glossary

## Ad Request

A request generated by an AI application or simulation that may later be matched
with a sponsored suggestion or monetization opportunity.

## AI Advertising

Advertising integrated into AI-generated responses instead of traditional banner
or popup formats.

## ASN

Autonomous System Number. A network-level identifier useful for fraud analysis.

## Batch Processing

Offline processing over accumulated historical data, handled in this project by
Spark.

## CEP

Complex Event Processing. Detection of meaningful multi-event patterns in a
stream.

## Consumer Group

A Kafka concept that allows multiple consumers to share topic partitions and
scale processing.

## Event Streaming

An architecture style where systems exchange data as ordered event records over
time.

## Flink

The stream-processing engine used for real-time fraud analysis in this project.

## Fraud Verdict

The decision outcome of a fraud check, such as `clean` or `fraud`.

## Keyed Stream

A stream partitioned by a key, such as `ip_hash`, allowing stateful per-entity
processing.

## Moderation Verdict

A planned decision outcome that reflects prompt safety, abuse, or policy risk.

## Prompt Manipulation

Attempts to shape or exploit prompt content in order to game monetization or ad
selection behavior.

## Redis

The in-memory data store used here for short-lived counters and shallow fraud
state.

## Request Simulator

The synthetic event generator used to produce normal and suspicious AI ad
request traffic.

## Shallow Fraud Detection

The first low-latency fraud layer that uses fast rules and Redis state before
the deeper streaming path.

## Spark

The batch analytics engine used for historical aggregation and ML training.

## Stateful Stream Processing

Stream processing that remembers prior events, such as recent counts per IP or
per session.

## Tumbling Window

A fixed, non-overlapping time window used for counting or aggregation.

## Sliding Window

A moving time window that allows overlapping observations for more continuous
rate analysis.

## Watermarking

A stream-processing technique used to reason about event-time progress and late
arriving events.
