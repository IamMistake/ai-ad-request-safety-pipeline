# Glossary

## Ad Request

A request generated by an AI application or simulation that may later be matched
with a sponsored suggestion or monetization opportunity.

## ASN

Autonomous System Number. A network-level identifier useful for fraud analysis.

## Consumer Group

A Kafka concept that allows multiple consumers to share topic partitions and
scale processing.

## Flink

The stream-processing engine used for real-time fraud analysis in this project.

## Fraud Verdict

The decision outcome of a fraud check, such as `clean`, `suspicious`, or `fraud`.

## Keyed Stream

A stream partitioned by a key, such as `user_ip`, allowing stateful per-entity processing.

## Moderation Verdict

The moderation decision outcome that reflects prompt safety, abuse, or policy risk.

## Requests Sender

The Kafka producer that replays generated labeled request datasets while publishing
only raw request payloads.

## Spark

The batch analytics engine used for historical aggregation and ML training.

## Stateful Stream Processing

Stream processing that remembers prior events, such as recent counts per IP or per session.

## Watermarking

A stream-processing technique used to reason about event-time progress and late arriving events.
