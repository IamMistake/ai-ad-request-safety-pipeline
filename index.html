Abstract

Overview

AI-powered platforms increasingly inject sponsored content into their responses, creating a new attack surface where bad actors craft requests that commit fraud or inject unsafe content. This pipeline evaluates every request through multiple defense layers before it reaches ad injection.

This project builds a real-time streaming pipeline that detects fraudulent ad requests and moderates unsafe content using Apache Kafka as the event backbone, Apache Flink for stream processing with 14 stateful fraud detection rules, and Apache Spark for offline ML model training. The pipeline simulates realistic ad traffic from 175k real GPT conversations, evaluates each request through multi-scope detectors (user, session, publisher), scores suspicious requests with a RandomForest classifier, and enforces content safety policies before allowing ad injection.

Key components include a request simulator with configurable fraud profiles, five Kafka topics for pipeline decoupling, Flink-based real-time fraud detection with watermarking and keyed state, a moderation service supporting both local rule-based and OpenAI API modes, and a Spark ML pipeline that trains and serializes fraud classification models from historical pipeline logs.

Real-Time Processing

Flink-based stream processing with event-time watermarks, managed keyed state, and per-identity windowed burst detection.

Multi-Stage Detection

Rule-based filtering (14 rules, 3 scopes) followed by optional ML-based RFC scoring for suspicious requests.

Batch Analytics

Spark ML pipeline trains RandomForest models from historical logs, computes risk rollups, and serializes model artifacts.

Architecture

Data Pipeline

Every request’s journey through five Kafka topics, three detection stages, and one ML training pipeline. Click a component in the diagram below to learn more.

Click a component above to see details.

1

Request Simulator

Generates synthetic ad request traffic from real GPT conversation data (WildChat, 175k prompts). Supports normal and fraud traffic profiles with configurable burst and bot patterns.

2

Kafka Event Stream

Five topics decouple all pipeline stages: requests.raw (ingress), requests.sus (suspicious), requests.clean (fraud-clean), requests.fraud (blocked), and ad.injection (approved).

3

Flink Fraud Detection

Assigns event-time watermarks, keys the stream through three stateful detectors (User → Session → Publisher), and routes by score: clean (<0.5), suspicious (0.5–0.8), or fraud (≥0.8).

4

RFC Scoring Planned

Consumes requests.sus and applies the Spark-trained RandomForest model to score suspicious requests. Cleared requests go to requests.clean; confirmed fraud goes to requests.fraud.

5

Content Moderation

Analyzes prompt content for safety using mock (rule-based keyword + TF-IDF) or OpenAI (omni-moderation-latest) modes. Prompt caching via SHA256 hash. Routes clean to ad.injection, unsafe to requests.fraud.

6

Spark Training

Exports historical logs, trains a RandomForestClassifier on features (scam keywords, ASN, fraud score), computes risk rollups per IP/publisher/ASN/session, and serializes model artifacts for RFC scoring.

Content Safety

Content Moderation

The moderation service analyzes prompt content for safety before forwarding to ad injection. It supports two provider modes.

Rule-Based Local Moderation

Default mode for local development. Uses keyword patterns, normalization, and TF-IDF similarity to detect unsafe prompts. No external API calls — fast and repeatable.

# No API key needed
MODERATION_PROVIDER=mock

# Uses ModerationAnalyzer with keyword rules
# and TF-IDF gating against reference corpus

OpenAI Moderation API

Calls the OpenAI Moderation API (omni-moderation-latest) for more accurate content safety checks. Requires an API key. Prompt caching avoids redundant calls.

# Set in .env
MODERATION_PROVIDER=openai
OPENAI_API_KEY=sk-...
OPENAI_MODERATION_MODEL=omni-moderation-latest

Moderation Flow

requests.clean → ModerationClient.analyze(prompt)
                 |- Check cache (SHA256 normalized prompt)
                 |- Mock/OpenAI analysis
                 '- Route result
                    |- Clean → ad.injection
                    '- Unsafe → requests.fraud
Batch Analytics

Spark Training

Spark processes historical export data to train fraud detection models and compute risk profiles for IPs, publishers, ASNs, and sessions.

Feature Engineering

Three features for the RandomForest model:

  • contains_scam — Regex match against scam keywords
  • asn — Autonomous System Number (network risk)
  • fraud_score_feature — Prior Flink fraud score

Risk Rollups

  • ip_risk_scores.json — Per-IP metrics
  • publisher_risk_scores.json — Per-publisher
  • asn_risk_scores.json — Per-ASN risk
  • session_risk_scores.json — Per-session fraud

Model Artifacts

  • fraud_model.pkl — Serialized RandomForest
  • model_metrics.json — Accuracy + classification report
  • feature_columns.json — Feature schema

Analysis

  • Shallow denials are mostly ip_burst combinations (especially with suspicious_ua).
  • Many sessions hit fallback IP 8.8.8.8, inflating repeated-IP signals.
  • Flink marks as suspicious at any score above 0.5, so suspicious dominates.
  • No requests exceeded the 0.8 fraud threshold in this test run.

WildChat Dataset

175k real GPT conversations from April 2023. Provides prompt text, moderation labels, 30+ languages, and unique conversation IDs used as session/publisher identifiers.

175,238 rows across 2 shards

GeoLite2

MaxMind GeoIP databases for IP-to-location resolution. ~92% of random public IPv4s resolve to a country. Used for country-hop detection and language/country mismatch rules.

City + Country databases

Traffic Profiles

Two traffic profiles: normal (realistic behavior) and fraud (bursts, bot patterns, suspicious IP churn) for controlled experiments.

Setup

Getting Started

Run the full pipeline locally in a few steps.

Pre-reqs
# Python 3.10+
# Docker + Docker Compose
1 Start infrastructure
docker-compose up -d
2 Install dependencies
pip install -r requirements.txt
3 Transform dataset
python scripts/transform_wildchat_user_prompts.py
4 Run the pipeline
# Terminal 1: Request simulator
python kafka/producers/request_simulator.py

# Terminal 2: Flink fraud detection
python flink_service/fraud_detection.py

# Terminal 3: Moderation consumer
python pipeline_consumers/moderation_consumer.py

# Terminal 4: Debug consumer
python test_consumer.py
5 Run pipeline tests
./scripts/test_full_pipeline.sh
./scripts/test_fraud_block_flow.sh
./scripts/test_moderation_block_flow.sh
6 Spark training
# Export historical logs
python spark_service/historical_exporter.py \
  --from-beginning --idle-seconds 30

# Run training
python spark_service/spark_training.py
